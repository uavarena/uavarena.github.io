# UAV Arena website

Source of the UAV Arena website: a virtual competition where autonomous fixed-wing UAVs fly on real ArduPilot autopilots, scored by an automatic referee.

Plain HTML and CSS, served by GitHub Pages from the `main` branch. Team registrations and company inquiries arrive as issues through the forms in `.github/ISSUE_TEMPLATE`.

UAV Arena is an independent project inspired by the Fighting UAV (Savaşan İHA) competition format. It is not affiliated with or endorsed by TEKNOFEST or its organizers.
